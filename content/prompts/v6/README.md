# Prompt v6（2026-10-10）

相对 v5（依据 `docs/review-n3-eval-2026-10-10.md` 对 v5 / DeepSeek 报告的预审）：

- `reading-system.md`、`perspective-system.md`：新增“不把牌面联想写成关于用户生活 / 他人想法 / 关系的事实”，给出不可写与可写的对照；只引用用户自己说过的事实；不用与问题无关的比喻。
- 读法：不再固定“从外部看 / 从内在看”，按问题选角度。
- 小行动：只写不需要别人参与的事，不再出现“联系 / 约 / 发消息给”或“联系 vs 不联系”二选一；形式不固定为“左边右边各写三条”。
- 反问：不以“吗 / 是不是 / 要不要”收尾，不固定“如果不……”开头，不预设用户没提过的人物或选项。
- `rewrite-system.md` 不变。
- 状态：**尚未用真实模型验证**这些改动是否真的减少了断言式推断与句式固化；只通过了离线（mock）检查。在人工审读和实测前，v5 的实测数字不能算作 v6 的。
