# 真机验收清单（需要你在手机上做）

电脑端的自动化测试不能替代真机。每项记录：设备 / 系统 / 浏览器版本、日期、结果、备注。

## A. 手机访问电脑上的实例
- [ ] 电脑 `pnpm build && pnpm start:lan`，手机连同一 Wi-Fi 打开 `http://<电脑局域网 IP>:3000`，页面正常。
- [ ] 默认 `pnpm start`（不带 lan）时，手机**连不上**（预期）。
- [ ] 手机上走完一次本地占卜并保存；刷新后还在；历史页能看到。
- [ ] 手机上无 service worker（http 非安全上下文），确认页面没有报错横幅。

## B. 安装与离线（需要 HTTPS，例如反向代理 / 隧道）
- [ ] Android Chrome：菜单里出现“安装应用 / 添加到主屏幕”，安装后独立窗口打开。
- [ ] iOS Safari：分享 → 添加到主屏幕；从主屏打开正常。
- [ ] 访问过 `/`、`/reading`、`/history` 后开飞行模式：主屏图标打开仍能用；本地占卜能走完并保存。
- [ ] 飞行模式下 AI 不可用，只剩本地解读，没有报错。
- [ ] 部署新版本后：出现“有新版本”横幅，点更新后正常。
- [ ] iOS：Safari 标签页和主屏应用的数据是否分开？（记录现象，决定文档怎么写。）

## C. 交互
- [ ] 触屏：长按洗牌、点选抽牌、翻牌、小行动按钮都容易点中。
- [ ] 分享图：生成预览、下载 / 保存到相册；字体、逆位牌旋转正常。
- [ ] 备份：导出下载、导入选择文件在该系统上可用。
- [ ] 系统读屏（VoiceOver / TalkBack）走一遍：抽牌、结果、保存状态是否被朗读。
- [ ] 系统“减少动态效果”打开后，翻牌 / 洗牌没有动画。

## C2. N2 之后新增的真机检查
- [ ] 到期提示：打开首页，看到“有一条记录到了回看的日子”；点“去回看”落在详情页的“回看”区，屏幕阅读时焦点在“回看”标题。
- [ ] “已回看”“保存回看并完成”“不再提醒”各点一次，状态与文案和预期一致；刷新后保持。
- [ ] 保存占卜后，结果页下方显示“安排在 … 回看”，“不提醒这条”“改到 3 天后 / 一周后”可点中（触控目标够大）。
- [ ] 抽牌前的“这次想要的帮助”下拉框：在 iOS / Android 上弹出系统选择器，选完能回到页面继续。
- [ ] 备份导出 / 导入：用 `docs/observation/` 的合成文件导入，冲突预览可读；导入后立刻切到别的 App 再回来，数据完整。
- [ ] 两个标签页（或主屏应用 + Safari）同时开，一边“不再提醒”，另一边提示自动消失。

## D. Docker
- [ ] `docker compose up --build` 后 `http://localhost:3000` 正常；手机访问不到（默认只绑回环）。

## 模拟器记录（不是真机）

2026-10-10，Xcode 里的 iOS 26.3 模拟器 / iPhone 17 Pro / 内置 Safari，生产构建 `pnpm start`（`http://localhost:3000`，非 HTTPS 的 localhost）：

- 通过：首页、情境卡、建档引导可见；“按住洗牌”长按 2.5 秒触发，iOS 没有弹出文字选择 / 放大镜；点牌翻牌（含逆位旋转）；跳过自解；本地解读保存；结果页下方显示“这条记录没有安排回看提醒”，点“3 天后提醒我”后显示“安排在 2026年10月13日 01:40 回看。”和“不提醒这条 / 改到3 天后 / 改到一周后”。
- 观察：翻牌动画进行中连续快速点击，只有第一下生效（1 秒内三连点只翻开了一张）；慢一点点第二、三张是正常的。真人是否会觉得“点了没反应”待观察。
- 未测：文件导出 / 导入（模拟器里选文件不方便）、分享图保存、SW 离线与更新、VoiceOver、“减少动态效果”、HTTPS 安装、手指实际大小下的点选。
- 结论：模拟器通过只说明 iOS WebKit 渲染与基本交互没有明显问题，**不能替代上面 A–D 的真机项**，也不是 VoiceOver / TalkBack 验收。
