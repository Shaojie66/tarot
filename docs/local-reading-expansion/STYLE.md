# 本地解读 v2 写作规范（扩写用）

> 来源：v2.1–v2.7 十轮 AI 盲评（`docs/review-local-reading-ai-prescreen-2026-10-10.md`）和 PRD（`docs/prd-local-reading-quality-2026-10-10.md`）总结出的规则。**规则里能自动检查的，都已写进测试**（`evals/local-quality.test.ts`、`evals/local-sweep.test.ts`）；这里写的是测试查不出来的判断。内容文件：`content/local-reading-v2.json`。

## 1. 声音

- **直接给出可核对的主张，再说怎么核对。**允许写“这组牌的重点是……”“先看清承诺，再决定放下哪一项”；不写“这三张牌不是答案”“我不替你做决定”这类免责。选择权靠结果页的“就做这个 / 改成我的版本 / 这次先不做”保障。
- **关于用户的处境、情绪、他人想法、关系，只用可以被否定的口径**：“可能……”“如果……”“……时”。关于**牌**的象征可以直说（“宝剑四讲的是暂停”）。
- 一句话里只放一层意思。评审多次指出“一行塞三层意思”（稳住自己 + 不必急着碰 + 期限例外）读起来是拼接。

## 2. 不要写（评审反复指出的）

| 类型 | 例子（不要写） | 改成 |
|---|---|---|
| 替用户确认状态 / 情绪 | “你其实已经知道……”“你只是还没……”“不安被压下”“情绪起伏是……” | “如果有一件事一直拖着，……”“可能在提示……” |
| 把状态当标签、再当行动 | “「X」是眼下的底色，「Y」是可以先动的一步” | 一句话要点（`oneLine`）+ 条件句，Y 不能是个要避免的状态 |
| 预设用户做过 / 有过 / 想过 | “你想了很久的计划”“你已经学到的”“想学的东西已经明确时”“刚才那件小事”“当初答应是出于‘应该’” | “如果有……”“如果已经……” |
| 预设用户要离开 / 要改变 | “走之前必须先处理……”“继续维持原样每个月要付出什么” | “如果要走一段过渡，……” |
| 替用户判断他人 | “对方不重视你”“双方没有在一起建造什么” | 只写成用户可以核对的问题 |
| 断言词 | 一定 / 注定 / 必然 / 肯定会 / 命中注定（`BANNED_PHRASES`）、`ASSERTIVE_PHRASES` | — |
| 通用安慰 | “你的价值不取决于别人有没有看见”“你的状态其实不差” | 说这次具体要核对什么 |
| 与问题无关的比喻 | “刹不住的自行车”“像在审一份合同” | 只用能直接对应牌面意象的 |
| 要求读者认领未确认的处境 | “原来的安排可能已经不像从前那样稳，先承认这一点”（前半句留了余地，后半句仍要求认领） | “如果原来的安排已经不像从前那样稳，可以先把这一点看清”（`先承认` 已进 PRESUPPOSED 扫描） |
| 整体点题与行动脱节 | 整体说“比较两边成本”，行动只排序在意的事 | 要么行动真的做这件事，要么把核对点收窄到行动能完成的范围；检查：核对点（`obstacle.focus`）与末牌三种意图的行动能否一句话接上 |
| 无具体问题时预设用户有目标 | “今天只学一个很小的东西”“做完记一句收获” | 写成可以不做的条件句：“如果今天有一件想碰一下的小事……没有也可以，不碰也算完成” |
| 合作类牌的行动只剩单人练习 | decide 试验只写“想得到什么信息” | 选项依赖别人时，把“需要谁、配合什么”写进试验要验证的信息 |
| 整体复述逐牌说明 | 整体与某张牌的说明逐字相同 | 整体用该牌的 `oneLine` |
| 问句预设 | “这次变动里……”“过渡期里……”“最近三次……”“休息之后……” | 条件问句：“如果……，……？”；问句追问的是这张牌的行动涉及的那件事（与 `next.aim` 同一条线） |
| 陪伴强制书写 / 记录 | “做完记一句感受”“只写下此刻……”“写完合上本子” | 陪伴行动不要求写字、记录、列清单、核对；给一个小动作或一个注意方向，做到哪里算完写清楚（测试全文扫描） |
| 未必成立的量 | “用省下的半小时……” | 不写结果里未必存在的时间 / 数量 |
| 替用户选 | “选更可承担的那一个”“只保留能承受的”“挑清单最短的那个先推进” | 标出、比较、作为一条参考；选哪个留给用户 |
| 行动依赖别人回应 | “请一个无关的人看，问他哪一句更清楚” | 行动一个人能做完；需要别人的部分只写成“准备好可以讲的三句话”，要不要讲由用户定 |
| 状态当标签 | gist 写成“只想不做”“离不开”“不安被压下” | 标签描述牌的提示（“还没开始的计划”“被拖住的变动”“没看清的信号”），不给用户贴状态 |

## 3. 延后类建议必须带例外

凡是建议“先不处理 / 延后 / 暂放 / 挪到明天 / 其余明天再说 / 等稳下来再……”，同一句里必须有“不紧急”或“有期限的事以期限为准”（测试全文扫描）。**只有真的在延后什么时才加**——喝水、慢呼吸这类行动不延后任何事，不要加（评审认为是补丁）。

- **优先改写，其次嵌入，最后才追加**：先看能不能改成不延后任何事的说法（“把一段完整的休息排进日程，给下一次行动留出力气”）；确实在延后，就把“不紧急”自然写进句子（“不紧急的决定，可以排在恢复之后”）；句尾追加“有期限的事以期限为准”是最后的办法。
- 扫描范围是**全部字符串**（逐牌的 situation / 说明 / 读法 / 行动、主题变体、主张的角色 / 立场 / 读法 / 行动 / 转折），不只是行动。让人暂停决定的说法也算延后：先不拍板、再做决定、先于决定、排在……之后、先等一晚、不用做任何决定。

## 4. 行动

- 一个人 24 小时内能独立做完，不依赖别人的回应；有对象、步骤或完成标准（“写下……”“选一件……给它二十分钟”“……做完就够了”）。
- **涉及关系的主题，行动只涉及用户自己**（“只写你自己的部分”），不预设联系、约、发消息给对方，不预设“一起”。
- 三种意图是三种任务，不是三种语气：
  - `clarify`：帮人分清一个关键区别。
  - `decide`：给比较标准、信息优先级或可逆的小试验，**不替用户选**。
  - `companion`：降低负担，仍围绕牌面；不强制写字、列清单、记录感受、核对；不预设有一件事要处理（要用到“那件事”时写成“如果有一件事……；没有就不用找”）。
- 不要在行动后面追加“做的时候留意……”（已删除；硬接的尾巴被评为脱节）。

## 5. 读法与追问

- 两条读法必须是**不同的条件、不同的下一步**，且以“……时，”或“如果……”开头（测试检查）。不写“从外部看 / 从内在看”的固定二分。
- 追问是开放式：以“？”结尾，不以“吗 / 是不是 / 要不要”收尾，不预设用户没提过的人或事（“如果……”开头的条件问句可以）。

## 6. 每个朝向要写的字段

见 `content/local-reading-v2.json` 里已有的牌。每张牌 `upright` / `reversed` 各一份：

| 字段 | 用途 | 要求 |
|---|---|---|
| `gist` | 编辑用的短标签（v2.9 起不再渲染给用户） | 2–8 字；描述牌的提示，不给用户贴状态 |
| `oneLine` | 整体综合三张牌时用 | **以“可能……”开头**的谓语；与本牌的 `situation` / `obstacle.text` / `next.text` 不是同一句，也不含它们的原话 |
| `tags` | 选共同解释用 | 用已有词表（见 §7）；每个朝向 1–3 个，不要为凑命中加不贴切的标记 |
| `situation` | 在“此刻”位置的说明 | 描述牌在这里的提示，条件口径 |
| `obstacle.focus` | 在“阻碍”位置时，整体里的“值得先核对的是：……” | 一个**有没有 / 是否 / 对不对得上**式的核对点，不是对用户的判断 |
| `obstacle.text` / `.check` | 阻碍位说明 / 读法一 | `check` 以“……时，”或“如果……”开头 |
| `next.aim` | 这张牌在“下一步”位置给的**方向**；按位置路径的整体用它收尾（“核对之后可以试的一步：……”） | 一个动词短语，不带句号，不是 `next.text` 的原话；三种意图的行动和 `next.question` 都要落在这个方向上（检查：能不能说“因为方向是 X，所以行动是 Y”）。涉及用户处境时用条件口径（“如果在考虑一次变动，先只定‘下一站’”） |
| `next.text` / `.check` | 下一步位置说明 / 读法二 | 同上 |
| `next.actions.{clarify,decide,companion}` | 三种意图的行动 | 见 §4，`{in}` 会被替换成“这份工作里 / 这段关系里 / 这件事里 / 这个选择里” |
| `next.question` | 追问 | 见 §5 |
| `byTopic.<topic>` | **只在**该牌在某主题下语境错配时才写（比如关系里读成职场协作、自我里读成“过渡”）。能把默认文字改成四个主题都通顺，就不写变体 | 可覆盖 `gist` / `oneLine` / `situation` / `obstacle` / `next`（含 `aim`）的部分字段；变体同样受全文扫描约束 |

**警惕的牌族**（评审里反复在主题上出问题）：合作 / 分工类（星币三、权杖三）→ 关系主题要改成“期待”；学习 / 练习类（星币侍从、星币八）→ 去留主题不要变成“安排学习”；离开 / 过渡类（宝剑六、死神）→ 关系、自我主题不要预设“要走”。

## 7. 标记词表与共同解释

- **标记**（`tags`）用于选共同解释或对应牌的变体，不是给用户看的。已用：`solitude reflect avoid closed-reflection upheaval aftermath ending ending-resist transition transition-stuck warmth enthusiasm energy depletion self-doubt pace-fast momentum pace-snag pace-rushed small-liking sensitivity emotion-high rest restless restart decisive consequence juggle overload cooperate cooperate-gap trial start-small plan-no-action`。**新增标记要在这里登记**（一句话含义），并说明哪个共同解释会用它。`closed-reflection` 表示隐士逆位的独处中反复转念，仅供三个后备主张的变体使用，不参与路由权重（见 §8）。
- **共同解释（focus）** 现有 8 个。原有 5 个：`small-trial`（节奏与试验）、`warm-juggle`（热情与兼顾）、`load-transition`（负担与过渡）、`settle-feelings`（安顿与恢复）、`invest-cooperate`（投入与配合）。v2.10 新增 3 个后备主张（`fallback: true`）：`inner-first`（先听自己；锚牌标记 `reflect` / `sensitivity`）、`rebuild`（收尾与重建；`upheaval` / `ending`。起初还把 `restart` 当锚牌，通读输出后降为搭档：只有宝剑四逆位在场时，主张里“什么已经告一段落”没有牌支撑）、`momentum-check`（势头与确认；`momentum` / `decisive`）。
  - **锚牌**：新主张都用 `requireAny` 要求至少一张带锚牌标记的牌在场，主张才有牌支撑；只靠三张搭档牌凑分不算命中（v2.10 的第一版模拟没加这条，占比虚高到 28%）。
  - **后备层**：`fallback: true` 的主张只接“非后备主张都不命中”的组合，不抢原来命中的组合；后备主张之间取分高者，同分按文件里的顺序。这是 12 张牌阶段的简化，牌和主张多起来之后要回头换成统一的打分规则。
  - **搭档标记可以不写角色句**：给了权重但 `roles` 里没有的标记，渲染时用这张牌自己按主题取值的一句话要点和说明（主题变体因此直接复用）。锚牌标记和语义最强的几个搭档必须写角色句，说明它和主张的关系。扩写到更多牌后**要新增主张**（例如大阿卡纳里的“自我认同”“转折与代价”“关系与边界”），新增一个主张需要：≥3 张牌的标记能命中它、`roles` 覆盖每个用到的标记、两条读法围绕同一个条件、三种意图的行动与追问、关系 / 自我 / 去留的变体检查，并**先写预先保留的组合与期望命中**（`evals/local-quality/reserved.json` 的做法）再看输出。
- **没有贡献标记的牌**（命中主张，但这张牌的标记不在该主张的 `weights` 里）：整体里用它的 `oneLine`，不再写“带来「……」这一层背景”。如果这张牌的默认说明会和主张相抵（比如“安顿与恢复”里末牌是热度、默认说明却催人向外推进），在该主张的 `support` 里按标记补一条衔接：`relation`（以“可能”开头，说明它对主张的作用）和可选的 `detail`（替换这张牌的说明）。`support` **不参与选主张**，加减它不会改变命中分布。
- 没有命中主张的组合走按位置的路径（整体 = 阻碍牌的核对点 + 三张牌的 `oneLine` + 末牌的 `next.aim`）。两拍对应牌阵自己的结构（卡住的地方 → 可以试的下一步）：整体先交代两拍，读法一 / 读法二分别展开，行动和问句落在第二拍上。命中率是质量指标之一：`evals/local-sweep.test.ts` 会打印各主张的命中分布，v2.10 的 12 张牌里 clarify 约 19.6%、companion 约 23.9% 的组合没有命中主张。


## 8. v2.11 后备主张的位置渲染

仅适用于 `fallback: true` 的三个主张。重点与三牌关系仍来自主张；读法一取阻碍位按主题解析的 `obstacle.check`，读法二、方向、行动与追问取末牌。`requireAny` 只负责选主张，不选择读法来源。首牌可影响选主张和关系句，不保证改变每个后续字段。

- 后备主张不再存通用 stance / branches / intentBranches / actions / questions；普通五主张保留原规则。后备 schema 严格区分，不能以废弃字段隐藏回退。
- `nextVariants.<tag>` 可覆盖 aim、companionAim、check、companionCheck、actions、questions，并可有 byTopic；`obstacleVariants.<tag>` 可提供 check、companionCheck 及 byTopic。check 用于后备路径中已知正逆位共用主题条件的修正，或下文约束下的重点衔接；仍由阻碍牌标记决定，不从锚牌取值。companionCheck 用于确有负担回退的阻碍读法。标记按牌面顺序取首个匹配项。无主题条目时默认变体再叠主题变体；牌在该主题已有 byTopic 条目时，**只使用变体 byTopic 中明确填写的字段**，未填回到牌面主题内容，不继承通用变体。即使牌面主题只改了 obstacle，这一保护也生效。
- 后备整体使用独立 fallbackClosing：理清“围绕这个重点，可以从这一步入手：{aim}。”，决定“把这个重点带进选择，可以先试：{aim}。”，陪伴“如果愿意，这次可以只做一点：{aim}；不想做也可以。”；不能沿用前文没有核对点的“核对之后”。
- 方向、条件、动作、问句整组检查：为什么这个重点使末牌成为下一步，动作产出怎样回应读法，问句是否仍落在该动作上。过渡句和主题词本身不是因果证据。不为降低雷同率添加牌名或同义词。
- 陪伴检查分析量、动作数量、完成压力和不做的余地，不只检查书写禁词。必要时按对应位置的牌提供轻量条件句，不恢复按主张固定的两条陪伴读法。
- 后备位置敏感性：同主题、意图、另外两张牌及主张不变时，换阻碍牌必须改变读法一与后续签名，换末牌必须改变后续签名；换牌与翻面分开统计。签名仅含两条读法、行动和追问。撞词率、不同签名数及重复份额只是描述指标，不代替语义审读。

### 首轮盲评后的衔接修订（2026-10-12）

牌的位置来源不变，但不能直接复用与重点无关的条件或动作。后备 `obstacleVariants.check` 也可用于把该阻碍牌的核对条件接回当前主张，必须保留该牌的实际限制，不能只加主张关键词。末牌变体的方向、条件、行动和追问必须使用同一判断标准；决定意图中不能从“个人在意”突然换成“验证成本最低”，也不能从“哪些还能用”突然换成“哪个让人起劲”。陪伴的方向和追问同样不能要求完成分析；需要时以低负担的共同方向兼容各意图，并为陪伴写独立追问，不能只在结尾加拒绝句。

若共用 `aim` 对陪伴仍要求分析，可在末牌变体中填写 `companionAim`，只在陪伴意图覆盖方向；该字段同样受逐字段主题保护。它必须对应实际的陪伴动作，不能用“整理判断”的方向配“望一会儿窗外”的动作。普通主张与共享牌面 schema 不变。

新增 `closed-reflection` 标记：隐士逆位的独处中反复转念。仅用于三个后备主张的阻碍/末牌变体，不加路由权重，避免与高塔逆位共用的 `avoid` 抢先命中同一份文本；原有牌义文本不改，路由与非后备输出须继续全量一致。

## 9. v2.13 后备路径写作规范（2026-10-28）

只适用于命中三个后备主张、并且阻碍位与末牌都写了 v2.13 槽的组合；其余路径不受影响。

**分工**
- 阻碍位决定“看什么”：判断标准 `standard`（理清）、比较标准 `compare`（决定），以及按方式写的动作句。
- 末牌决定“怎么看”：首选方式 `modes`，最多 3 个，首选在前；每种方式配一句读法二。
- 组合规则：取末牌偏好中第一个阻碍位写了的方式。理清找不到可用方式时退回 v2.12；决定找不到时用阻碍位的收集句 `gather`。

**9 种方式**
- 回看：回到一次真实发生过的情形。
- 小试：真的做一件可撤回的小事。
- 查证：查一处事实。
- 写下来：写下一句，并统一带“不想写，在心里说给自己也可以”。
- 停一拍：现在花两分钟写一句，不过夜。
- 减一项：真的减掉；决定模式写成“各写下来，划掉一项”。
- 歇：醒后看最先自己冒出来的是什么。
- 补：先停下来，想想哪一部分最耗劲。
- 缓：等心里平静一点，把事实和担心分成两堆。
- 同一阻碍位下，各方式句必须是不同的做法，不能只是换个说法；产出必须能回答本条标准。

**句子规则**
- 读法二：“末牌在提示，〈语气〉，〈方式〉。”只写态度，不写对象，不下断语。
- 条件式引子 `objectIf`：“如果……，先看……”，不把用户的处境写成已知。
- 阻碍说明 `blocks`：“挡住的可能是……：……”，写这张牌挡在哪里，不写成建议。
- 整体末句是桥接句：先接住主张，再落到 `objectIf`。读法一只给标准；决定的读法一是 `compareLens`，只陈述，不布置任务。
- 陪伴：不出判断题，只给一次拒绝出口，逐牌说明用画面句，追问是接收式的；整体只放陪伴主张句和语气收尾。
- 通用：
  - 行动带停止句；
  - 推迟类说法必须带“不紧急”；
  - 关系主题只写自己这一边，不出现“联系 / 一起 / 告诉对方”；
  - 不写“一定 / 注定 / 往往就是 / 可能就是”。

**评审口径**（用户 2026-10-27 裁定）
- 陪伴意图只换阻碍位时，看读法一和阻碍说明是否变化。
- 换末牌时，同一标准下行动换成另一种观察方式，算实质变化；行动逐字相同或只换了措辞，不算。

**护栏**（测试）
- 换末牌后行动逐字相同的比例 ≤ 10%；
- 每个阻碍位至少写 3 种方式；
- 收集句不与按方式写的句子近似重复；
- 方式审读表的指纹与当前内容一致。
