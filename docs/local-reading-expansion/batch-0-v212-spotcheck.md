## P07

### 甲

主题：自我；意图：做个决定

此刻：星币三（逆位） / 阻碍：星币侍从（逆位） / 下一步：高塔（正位）

整体：这组牌的重点是先看清什么还在、什么已经告一段落，再从一小块重新开始。星币三（逆位）可能在提示完成标准还没定下来；星币侍从（逆位）可能在提示重新开始可以先小小地试一次；高塔可能在提示原来的安排被震动过。把这件事里那件停在纸面上的打算带进比较；做法上，先把最基本的几件事稳住。

此刻说明：标准模糊的提示：对“做完”的标准可能还没定下来。

阻碍说明：重新开始不用一步到位：先做一份小功课，换一点实际的了解。

下一步说明：如果原来的安排被震动过，先分清哪些部分还能用、哪些已经不行。

读法一：做比较之前，先核对这件事里那件停在纸面上的打算：打算和行动之间，是否缺一个明确的开始。

读法二：末牌在提示，变动之后先稳住基本的节奏，其余的等看清了再动。

行动：先保证基本节奏不乱，再抽一小段时间做一次，结果只当作比较选项时的一条参考：给这件打算定一个明天就能开始的动作，小到二十分钟内做得完。做不完就停在这里，基本的节奏比这一步更要紧。

追问：打算和行动之间，是否缺一个明确的开始？这一点会怎样影响你对各个选项的比较？
