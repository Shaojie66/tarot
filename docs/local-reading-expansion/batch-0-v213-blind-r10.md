主题：事业；意图：理清现在的处境

### 甲

此刻：星币二（正位） / 阻碍：隐士（逆位） / 下一步：死神（正位）

```
整体：这组牌的重点是先看清什么还在、什么已经告一段落，再从一小块重新开始。星币二可能在提示手头同时顾着几件事；隐士（逆位）可能在提示独处是在整理还是在回避；死神可能在指向一个做法已经完成了它的作用。先从工作里这段常一个人想事情的时间看起；做法上，找出一处可以告一段落的地方。

此刻说明：同时顾着几件事的时候，要动的那一块得小到挤得进去。

阻碍说明：想法只在心里打转、没有拿到外面反馈时，容易越想越闭合。

下一步说明：如果有个做法越做越费力，对照一下它当初的目的，看是不是可以告一段落。

读法一：先核对工作里这段常一个人想事情的时间：这段独处是在整理，还是在绕开什么。

读法二：末牌在提示，收尾可以从减掉一小处开始。

行动：先把一个人时反复想的事减掉一件，看剩下的时间是安静了，还是空了。减掉就停。

追问：这段独处是在整理，还是在绕开什么？
```
