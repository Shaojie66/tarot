主题：事业；意图：理清现在的处境

### 甲

此刻：星币二（正位） / 阻碍：权杖王后（逆位） / 下一步：宝剑骑士（正位）

```
整体：这组牌的重点是把势头用在一件事上，推进前先确认最关键的一处。星币二可能在提示手头同时顾着几件事；权杖王后（逆位）可能在提醒补给是否跟得上投入；宝剑骑士可能在给出果断的力量。先从工作里近来的投入和补给看起；做法上，选最直接的一步，把事情往前推。

读法二：末牌在提示，目标清楚的时候，直接的一步比反复盘算有用。
```
