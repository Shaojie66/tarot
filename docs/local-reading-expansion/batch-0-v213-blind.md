主题：自我；意图：理清现在的处境

### 甲

此刻：星币二（正位） / 阻碍：权杖八（正位） / 下一步：宝剑骑士（逆位）

```
整体：这组牌的重点是把势头用在一件事上，推进前先确认最关键的一处。星币二可能在提示手头同时顾着几件事；权杖八可能在给出推进的势头；宝剑骑士（逆位）可能在提醒速度会压过判断。先从这件事里推进得很快的这件事里最容易出错的环节看起；做法上，动手之前，先看一眼后果。

此刻说明：同时顾几件事的时候，势头要收拢到一件上，而不是平均分。

阻碍说明：如果有一件事悬着，势头可以用来把它推到有结果；推之前先确认最容易出错的一处。

下一步说明：如果事情不紧急，推进前先把最可能的后果过一遍。

读法一：先核对这件事里推进得很快的这件事里最容易出错的环节：这个环节的前提是否已经确认。

读法二：末牌在提示，越急越要先停一拍。

行动：推进前先停一拍：写下最容易出错的那个环节靠的是什么前提，等一晚再看它还站不站得住。

追问：这个环节的前提是否已经确认？
```
