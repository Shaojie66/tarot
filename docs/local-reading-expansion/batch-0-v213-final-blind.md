# 匿名解读对照材料

只读本文件，不查其他材料，不猜版本或作者。P01–P18 是同一牌阵的两种文本；S01–S12 是同一主题和意图下，只换了一张牌的两个牌阵，检查后续文字是否随之有实质变化。甲乙在每组独立打乱。未提供问题正文，请只按主题、意图和牌阵判断。

每段按观点、三牌关联、主题、行动、语言各给 0–2 分（0=缺失或明显问题，1=部分，2=充分），不要因字数或措辞变化自动加分。单独判断“重点 → 核对什么 → 下一步行动”是否连成一条线 coherent=true/false：读法里要核对的对象和判断标准，行动是否仍然在做同一件事、用同一个标准；套一句收尾不算因果证据。三牌关联看三张牌是否各有有意义的贡献，而不是只数是否出现牌名。保留问题原句，具体矛盾不能被总体偏好抵消。

陪伴样本另逐项给出分析负担、任务数量/负担、完成压力各 0–2（越低越轻），拒绝空间 0–2（越高越足）。同时看整体、逐牌说明、两条读法、行动与追问，不只看是否要求书写。明确比较是否有一方增加负担及原句。

S 组另判断：meaningfulDifference（后续文字的差异是否来自换掉的那张牌的含义，而不是只换了可互换的小活动）、coherentA、coherentB。
