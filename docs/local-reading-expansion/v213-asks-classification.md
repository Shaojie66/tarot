# v2.13 第 1 步：阻碍位标准按“要回答的问题”归类

日期：2026-10-26。状态：**关口未通过**（预计跳过比例超过 40%），等待用户选择后续方向。只做归类与估算，未改代码、内容或测试。

## 归类：8 类（关口要求 ≤ 10，通过）

| 类别 | 标准在问什么 | 阻碍位朝向 |
|---|---|---|
| premise 前提 | 前提是看到的事实，还是猜测 | 权杖八正、宝剑骑士正、高塔逆 |
| cause 卡点 | 卡住 / 拖住 / 停不下来，原因是哪一种 | 权杖八逆、宝剑六逆、宝剑四逆、隐士逆 |
| capacity 承载 | 补给、资源、精力是否撑得住 | 权杖王后逆、宝剑六正、星币二逆、宝剑四正 |
| priority 收窄 | 是否已收窄到一件、排在前面 | 权杖王后正、星币二正 |
| specific 说清 | 能否说到具体、可检验 | 星币三逆、星币三正（含 3 个主题变体，均属此类） |
| start 开始 | 是否有明确、足够小的开始 | 星币侍从逆、星币侍从正 |
| worth 值不值 | 继续 / 保留 / 去做，用处和代价哪个更大 | 死神正、死神逆、高塔正、宝剑骑士逆 |
| voice 自己的声音 | 哪些是自己的，哪些是外加的（建议、情绪） | 隐士正、圣杯侍从逆、圣杯侍从正 |

24 个朝向都能归入一类，没有硬塞的；只有 worth 把“目的还成不成立”（死神正）和“后果承担得起吗”（宝剑骑士逆）放在一起，这是最松的一类。

## 估算：末牌 × 类别，能写出“产出能回答这个问题”的动作吗

逐个判断 24 个末牌的做法（如高塔逆“查证一次”、宝剑四正“排一段休息”）能否为每一类问题提供证据。估算结果：

- 可写动作 86 / 192 条（末牌 × 类别），**跳过 55%**；按实际组合（扣除同一张牌不能同时在两个位置）加权，**跳过约 59%**。
- 各类别能接的末牌数：承载 16、开始 13、收窄 12、说清 12、值不值 11、卡点 9、前提 8、自己的声音 5（/24）。
- 跳过多的原因：休息、补能量、让情绪落一落这类末牌（宝剑四正、权杖王后逆、圣杯侍从逆）本来就不该产出证据，只能接 1–2 类；“自己的声音”只有安静、外化、轻试几种末牌接得上。

这是逐格的判断估计，没有实写；真写时通常还会再降一些。

## 关口结论

类别数通过，跳过比例**未通过**（约 59% > 40%）。按事先约定，停在这里，不开始写动作。

跳过的格子会退回 v2.12 的写法：行动来自阻碍位、末牌只给节奏和停止句。这些格子前后是连贯的，只是换末牌时动作不变。

## 可选方向

**甲：照原方案做，接受约 60% 跳过。** 只写 86 条动作。约四成组合换末牌后动作实质变化，其余只变节奏。工作量最小，但“末牌决定动作”只在少数组合成立。

**乙（推荐）：把“末牌给动作”改成“末牌选观察方式，阻碍位按方式写动作”。** 定 5–6 种观察方式（回看一次具体经历、做一次可撤回的小试、查证一处事实、说出来或写下来、停一拍过一晚、先减掉一项）。每个阻碍位只为自己的标准能用上的方式各写一句动作（预计每个 2–4 句）；每个末牌声明首选方式和备选方式。组合时取末牌首选方式中、阻碍位支持的那一种。

- 连贯由构造保证：动作是阻碍位按自己的问题写的，换末牌换的是观察方式，不会答非所问。
- 跳过只在末牌的首选和备选方式阻碍位都不支持时发生，预计明显少于甲，具体比例要在小样里实测。
- 代价：同一种方式的末牌之间，动作相同，只有节奏不同；内容量约为 24 × 3 句动作，加上 24 条方式声明。
- 这正是 v213-plan.md 第 1 节原本写的“同一标准，多种观察方式”；Opus 否决的是“读法一改由末牌提供”和“行动后面挂判断标准”，不包括这个方向。

**丙：降低要求。** 不追求换末牌后动作变化，只做连贯修正（回指词改用中心词、决定配对、陪伴修正）。末牌退回只管节奏。
