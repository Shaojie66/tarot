## 做了什么

| 意图 | 新写法 | 槽的来源 |
|---|---|---|
| 理清 | 行动和追问由末牌按阻碍位的类别（`kind`：打算 / 做法 / 推进）给出，只回指阻碍位的 `ref` | 阻碍位 `ref`、`kind`；末牌 `move[kind]` |
| 决定 | 读法一说明比较尺子（`compareLens`）；行动是末牌的比较方式（`weigh`）＋阻碍位的比较标准（`compare`）；追问＝`compare`；去掉“结果只当作比较选项时的一条参考” | 阻碍位 `compare`、`compareLens`；末牌 `weigh` |
| 陪伴 | 不渲染 `standard` / `probe` / `object`；读法一是条件式的 `light`；行动 `lightAct`（含一次拒绝出口）；整体收尾是末牌的语气 `lightAim`；追问是接收式（“说到…，现在最先浮上来的是什么？”）；逐牌说明用每张牌的画面句 `image`，不再共用“放着就好” | 阻碍位 `light`；末牌 `lightAct`、`lightAim`、`lightReading`；24 个朝向的 `image` |

版本：内容 `local-v2.13-sample`，契约 `local-v2.13-sample-contract`。v2.12 原文件备份在本机 `tmp/backup-v212/`。

## 已知问题（需要盲评判断，不靠自动检查）

1. **理清的读法一与行动可能各说各的**：读法一仍是阻碍位的判断标准，行动换成末牌的动作后，部分格子里行动不再回答这个标准（如权杖八 × 死神：读法一问“前提是否已确认”，行动是“选一处可以暂时不推的地方”）。这是“末牌决定动作”的直接代价，要看评审是否判为不连贯。
2. **决定的方式与标准有时配得勉强**：如宝剑骑士逆位的“写一句急着选它的理由”配权杖八的“哪个选项的前提还停在猜测”，两者关系要靠读者自己补。
3. **陪伴追问每个主题只有一句**：所有走新写法的陪伴组合，同一主题下追问完全相同。撞词率仍在线内，但读多了会察觉。
4. **整体收尾未动**：理清仍是 v2.12 的“先从{object}看起”（带预设）；决定变成固定的“这次比较只用同一把尺子”。
5. **主题变体未补新槽**：星币三逆位在关系 / 自我 / 抉择主题下有单独条目，这些仍走 v2.12。

## 验收口径的一处调整（用户已确认，2026-10-26）

“换阻碍位后行动必须变化 100%”这一条，对走新写法的陪伴组合改为“读法一必须变化”。原因：校准稿里陪伴的行动本来就由末牌给（例 3、4），阻碍位体现在读法一。其余意图和 v2.12 组合仍按原规则检查。

## 第二轮：方向乙（末牌选观察方式，阻碍位按方式写动作）

日期：2026-10-26。依据：Opus 复核（理清 27 格中 14 格未回应读法一；决定 27 格中 12 格不成立）、`v213-asks-classification.md` 的关口结论，以及用户选择的方向乙。

### 结构

- 6 种观察方式：回看（recall）、小试（trial）、查证（check）、说出来 / 写下来（say）、停一拍（pause）、先减一项（drop）。
- 末牌只声明 `modes`：首选在前，最多 3 种。第一轮的 `move` / `ref` / `kind` / `weigh` 已删除。
- 阻碍位为自己用得上的方式各写一句：理清写 `modes`，决定写 `compareModes`（在每个选项上怎么看）。每句的产出都必须能回答本条的判断标准或比较标准；用不上的方式不写。
- 组合规则：取末牌偏好里第一个阻碍位写了的方式。理清没有可用方式时，整格退回 v2.12；决定没有可用方式时，用阻碍位的 `gather` 句。
- 读法一与追问仍是阻碍位的标准，因此行动和读法一由同一处内容写成，连贯不再依赖拼接。
- 一并修正：
  - 主题变体：主条写了新槽时，主题变体必须写全，由 schema 校验；星币三逆的 3 个主题变体已补写。
  - 决定的读法一只陈述，不布置任务（schema 校验）。
  - 陪伴追问的名词按主题取；自我主题改为“说到自己”。

### 实测（只算阻碍位和末牌都在小样里写了新槽的组合，各 1372 个）

| | 结果 |
|---|---|
| 理清：跳过、退回 v2.12 | 25 / 1372，**1.8%** |
| 决定：没有可用方式、改用收集句 | 25 / 1372，**1.8%** |
| 同一阻碍位下换末牌，行动实质不同（事业主题，两两比较） | 理清 54 / 66、决定 54 / 66，均 **82%** |
| 每个阻碍位在 6–7 个末牌下用到的方式数 | 3–4 种 |
| `pnpm check` | 通过，647 passed / 8 skipped（`tmp/check-v213b.log`） |

剩下 18% 是首选同一方式的末牌：动作相同，只有读法二不同。这是方向乙事先说明的代价。

### 局限与仍待解决

1. **小样里的 7 张末牌都偏“去做”**，跳过比例因此偏低。休息型末牌（宝剑四正、权杖王后逆、圣杯侍从逆）可声明的方式很少，写全后跳过比例会上升；估计在 10–20%，以写全后的实测为准。
2. **逐句质量仍需审读**：连贯由构造保证，但每一句是否自然、是否偏重，仍要人看。例如死神正 × 小试写成“换一种更省力的方式做一次”，读起来有点生硬。审读量随句子数增长（约 24 × 4 × 2 句），不再随组合数增长。
3. 陪伴追问每个主题仍只有一句。
4. 理清的整体收尾仍是 v2.12 的“先从{object}看起”，带预设。
5. 测试中的 v2.13 断言检查的是“方式按偏好选、动作取自阻碍位对应方式”这一构造规则，不判断语义。

## 第三轮：三种“停下来”的方式＋ Opus 第二轮修正

日期：2026-10-26。依据：Opus 第二轮复核（`tmp/opus-v213-review-r2.md`）；用户选定“歇、补、缓”三种停法。

### 改动

- 新增三种停法：歇（rest）、补（refuel）、缓（settle）。今晚不布置任务，之后再看同一个问题。小样新加入三张休息型末牌：宝剑四正（歇）、权杖王后逆（补、歇）、圣杯侍从逆（缓、歇）。
- **读法二跟着方式走**：末牌为每种声明的方式写一句 `readings`（schema 强制配齐），选中哪种方式就用哪句。修复了 Opus S1：上一轮 30 格中有 11 格走的是末牌的第二方式，读法二与行动不一致。
- 决定模式没有可用方式时，用阻碍位的收集句；休息型末牌在前面接 `gatherLead`，例如“先歇一会儿，状态好了再……”。不再退回带“参考套话”的 v2.12 写法。
- 每个阻碍位的 `modes` / `compareModes` 至少 3 种（schema 校验，对应 Opus S5）。
- 逐句修改：采纳 Opus 第二轮的改写建议，包括去掉“出错”“后悔”的预设；宝剑骑士逆的比较标准与判断标准对齐；星币三逆不再“查原来怎么说”；死神删去“试选项”；收集句不再与“先减一项”等同；宝剑骑士正改为偏好“小试、写下来”。
- 测试（对应 Opus S4）：
  - 方式选择改为对照人工审过的表 `evals/local-quality/v213-mode-table.json`（180 格）；
  - 断言读法二取自所选方式；
  - 新增收集句与按方式写的句子近似重复检查（二字组 Jaccard < 0.5）。这项检查当场拦下星币三逆的一处重复，已改写。

### 实测（阻碍位和末牌都写了新槽的组合，共 1696 个）

| | 结果 |
|---|---|
| 理清：跳过、退回 v2.12 | 6 / 1696，**0.4%**（宝剑骑士逆 × 星币侍从逆） |
| 决定：没有可用方式、改用收集句 | 170 / 1696，**10%** |
| 同一阻碍位下换末牌，行动不同（事业主题，两两比较） | 理清、决定均为 127 / 138，**92%** |
| 涉及休息型末牌的换牌对 | 72 / 72 行动不同 |
| `pnpm check` | 通过，648 passed / 8 skipped（`tmp/check-v213c.log`） |

### 局限

1. 92% 统计的是所用方式不同，不等于语义上实质不同。尤其是“歇”与“停一拍”，以及“补”与“缓”之间，是否真的不同，需要盲评判断。
2. 三种停法的句子在各个阻碍位之间句式相近（如“先回点劲，再……有劲的时候……”）。读多了会察觉，审读时要专门看。
3. 小样的 10 张末牌里没有隐士、圣杯侍从正等方式更难归类的牌，写全后的跳过比例仍以实测为准。
4. 沿用的旧问题未处理：理清收尾带预设、陪伴追问每个主题只有一句、决定收尾是固定句。
5. 方式选择对照表由负责人审过，仍待用户确认。

### 决定记录（2026-10-26）

- 休息型末牌以“歇、补、缓”为准；Opus 窗口里“同意第 2 条”（休息型末牌退回 v2.12）由用户宣布作废。
- 方式选择对照表每格新增 `reviewed`，只能由用户填写，AI 不得代填。测试在小样期只统计“待人工审”的格数，写全后改为未审即失败。
- Flash 提出的两处小修改留到盲评之后再做，以免盲评材料与代码不一致：P16 的陪伴追问改由末牌提供；`lightAim` 增加语气约束。
