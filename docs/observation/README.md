# 观察用合成数据

只含合成内容（问题以“（合成）”开头，id 以 `obs-` 开头），不含任何个人信息，可以放心给参与者使用。

| 文件 | 内容 | 用途（见 `docs/observation-protocol.md` 的任务 5 / 7） |
|---|---|---|
| `backup-due-recall.json` | 2 条记录；其中一条带一个**已到期**的回读（到期日 2026-10-04） | 先在干净浏览器里导入它：首页 / 历史会出现“有一条记录到了回看的日子”，用于任务 5（去回看 → 已回看 / 不再提醒 / 保存回看并完成） |
| `backup-conflict.json` | 与上面第二条记录同 ID、但“当时的决定”不同 | 在导入过上一个文件的浏览器里再导入它：出现冲突预览，用于任务 7（默认保留本机、勾选才覆盖） |

准备步骤（每位参与者一个干净的浏览器配置 / 无痕窗口）：

1. `pnpm build && pnpm start`，浏览器打开 `http://localhost:3000/history`。
2. 导入 `backup-due-recall.json`（预览应显示新增 2 条、回看提醒 1 条），确认。
3. 任务 1–4（不经指导的完整占卜）在**另一个**干净窗口做，避免合成记录干扰“找回这次记录”。
4. 任务 5 / 7 再回到第 2 步的窗口做。

这些文件用于观察，不要当成备份导出格式的唯一样例（格式以 `src/features/reading/backup.ts` 为准）。
