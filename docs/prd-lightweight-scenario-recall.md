# PRD · 轻量化改造：情境卡 + 首访建档 + 未来回读

> **执行状态修订（2026-10-10）**：入口和建档已经实现；回读目前具备安排和到期入口，尚缺用户可操作的完成闭环。下一轮以 [可控回读与可信数据 PRD](prd-recall-reliability-2026-10-10.md) 为准，技术证据见 [v1.2 复评](review-v1-2-2026-10-10.md)。微定向、自解收起与额外反思提示暂缓，不是待自动补齐的发布要求。首访建档保留；“本次意图”和长期偏好分开，AI 发送说明必须覆盖 intent。
>
> 下文为原始设计来源；其中竞品“已验证”等断言没有在仓库中附可追溯证据，本轮不据此作效果承诺。“永不二问”只适用于偏好仍被成功保存的同一浏览器站点；不能承诺清除站点数据、存储失败后仍记住。建档在本机保存，但派生的本次意图会在用户选择 AI 解读 / 换视角时发送。

## 0. 一句话

用户打开 → 点一张情境卡（1 步）→ 洗牌 → 翻 3 张 → 解读 → 保存。全程无长问题输入框；首访只建档 1–2 屏选择题、存本地、永不二问；隐私与"不预测"红线不变。

## 1. 三个已锁定决策

| 决策点 | 结论 | 说明 |
|---|---|---|
| 首访建档是否保留 | **保留**（用户不同意砍掉） | 做成注册时一次性收集：1–2 屏、全选择题、可跳过、存本地。不表单式建档 |
| 情境卡文案腔调 | **浮罗绘心式克制提问** | 不用 WooMoo"第二人称纠结推销"腔；用安静、克制的反思式问句，贴合产品人格 |
| 未来回读（Hindsight） | **确认纳入 P0** | 取代上一版"跟进提醒"：给某次抽牌设未来日期提醒、到点回看，非行动督促 |

## 2. 首访建档（新，替代"占卜时逐步收集"）

### 数据模型（沿用 settings 范式，新增一个 localStorage key）

`tarot:profile:v1`，纯函数 + `useSyncExternalStore`，与 `src/features/settings/settings.ts` 完全同构。

```ts
// src/features/profile/profile.ts（新）
export interface Profile {
  /** 建档完成标志；未建档时占卜走"未建档"分支 */
  onboarded: boolean;
  /** 牌想帮你做的事 → 决定解读语气（对应线下"理解 vs 建议"澄清） */
  intent: "clarify" | "decide" | "companion" | null;
  /** 主题偏好（多选，用于排序入口与每日焦点） */
  topics: Topic[];
  /** 未来回读的默认节奏（可跳过） */
  recallCadence: "none" | "3days" | "7days" | null;
}
export const DEFAULT_PROFILE: Profile = { onboarded: false, intent: null, topics: [], recallCadence: null };
```

### 交互：1–2 屏、每屏一题、可跳过

**第 1 屏**（onboarding 弹层或 `/welcome` 首访页）：

> 夜深了，先花几秒定个方向。（可随时跳过）
> 你这次想牌帮你—— [理清现在的处境] [做个决定] [只是陪我说说话]

**第 2 屏**（可整体跳过）：

> 你平时最常为哪类事来？（可多选，先不选也行）
> 事业 · 关系 · 自我 · 去留

**未来回读节奏**（并进第 2 屏或放设置页，首访不强求）：

> 抽完想不想过几天回来，看看当时的自己？ [不用] [3 天后] [一周后]

- 全部门可选、可跳过；建档结果存本地，**永不二次询问**。
- 建档缺失时占卜不阻塞：仍走"未建档"分支（详见 §4 状态分支），只是语气用中性默认值。

### 明确不收

姓名、生日、星座、注册登录、手机号。依据：Labyrinthos 唯一头部必注册也只收一道化身选择题；本产品无占星功能不需要生日（研究：区分已验证/推断）。

## 3. 情境卡（改造 /reading 入口）

### 卡片设计（浮罗绘心式克制问句，非推销腔）

主入口 5 张卡（替代现在的"选主题 4 按钮"）：

| 卡 | 文案（克制版） | 对应主题 |
|---|---|---|
| 关系 | 这段关系里，我在看不清什么？ | relationship |
| 事业 | 留在原地，还是换个方向？ | career |
| 自我 | 我在跟自己较什么劲？ | self |
| 去留 | 两个选项之间，我在怕什么？ | crossroads |
| 此刻 | 没有具体问题，就想看看此刻的自己 | （无题） |

- 点卡即"选题 + 出题"合并成一步（WooMoo 已验证形式，但文案改克制）。
- 第 5 张"此刻"对应"无题也抽"共识（Trusted Tarot Daily / WooMoo / Golden Thread 三源印证）。

### 微定向层（点卡后 0–2 道，均可跳过）

复刻线下 3–5 分钟问题澄清（可验证），但不打断节奏：

1. *这个问题，是关于你，还是别人？* （选"别人"→ 自动改写为"我需要什么才能安心"，对应线下改写技术）
2. *你更想要理解，还是建议？*（与首访 intent 联动：建档已选则此处可省略）

两道都跳过 → 直接洗牌，用建档 intent 定语气。

### 高级入口

"自己写一个问题"收进卡片区底部的一个次级入口（不是主流程），保留现有 AI 改写作为可选。

## 4. 新流程状态机

```
打开 /reading
  ├─ 未建档 → 情境卡下方出现一次建档引导（可跳过）
  ├─ 点情境卡（5 选 1）
  │    ├─ 微定向 0–2 题（可跳过）
  │    └─ 无题分支：跳过微定向，直接"此刻"态
  ├─ 洗牌（保留长按仪式锚点）
  ├─ 翻 3 张
  ├─ 自解（默认收起，可展开；不再默认展开）
  ├─ 解读（语气由 intent 决定；"此刻"态用陪伴语气）
  ├─ 反思提示（Golden Thread reflective prompt 式，一句可跳过）
  └─ 保存 + 可设"未来回读"提醒
```

### 未来回读（Hindsight）

- 保存后提供可选：*过几天回来看看当时的自己？* [不用] [3 天后] [一周后]
- 数据：新增 `tarot:recall:v1`（localStorage，沿用 daily 范式），纯本地；不写进记录本身（不动 schema）。
- 到期呈现：首页/历史出现一条轻量提示，点击 → 跳回该记录详情 → 聚焦回看区。**非行动督促，是"回看当时的自己"**，贴合日记本定位。
- 删除记录 / 清空时级联清理（在现有 `deleteRecord`/`clearEverything` 补一行）。

## 7. 风险与边界

| 风险 | 缓解 |
|---|---|
| 建档"保留"却变成负担 | 全选择题、可跳过、1–2 屏、存本地永不二问；不做表单式建档 |
| 情境卡太"推销" | 用克制问句（浮罗绘心腔），不用 WooMoo 第二人称推销腔 |
| 未来回读变督促 | 定位"回看当时的自己"非行动督促；默认不打扰、可设可不设 |
| 隐私红线被破坏 | 建档/回读全本地；不含姓名生日星座；分享仍走白名单；可加"本次不保存"开关（浮罗绘心已验证） |
| 无题分支质量 | "此刻"态用陪伴语气（intent=companion 默认）；不强行造问题 |

## 8. 不做（明确边界）

- 不做云端同步 / 账户系统 / 付费。
- 不做"测测"式生日建档与重运营付费（反面参照）。
- 不把回读做成系统推送（Web Push）；仅站内轻提示。
