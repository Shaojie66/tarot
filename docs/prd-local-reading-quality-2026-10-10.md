# PRD · 本地解读要有观点

> 日期：2026-10-10；初版基线：`2ed0aba`；本轮复评：`00364cb`。v2.1 已实现 12 张牌的内容原型；第 8 节为待实施的 v2.2 产品修订。
> 用户已明确：不满意的是**本地解读**，原因是“太过笼统、不敢讲话、太多防御性语言”。未提供具体原文，本文件使用合成样例，不代替用户自己的体验记录。
> 实施顺序：[PLAN v1.5](PLAN.md)；当前证据：[v2.1 技术复评](review-local-v2-1-next-plan-2026-10-10.md)。第 1、5 节的“当前”指初版 v1 基线，作为历史对照保留。

## 1. 产品判断

本地解读需要交付一个有分量的观察：这组三张牌值得先看什么、为什么这样读、今天具体能做什么。当前首段主要列牌名与关键词，正文拼接单牌百科，末尾再劝用户放慢、别急、不必处理。文字不少，新增的判断很少。

上一轮计划过多强调避免出错，缺少对解释价值的正向要求；部分测试甚至把免责句作为必要内容。这次应纠正：允许清楚地说“这组牌的重点是过渡成本”“先查清这一项，再比较两个选项”。选择权由拒绝、修改与跳过的真实操作保障，不靠每段重复“我不替你决定”。

这也不是把“也许”全部删掉就能解决。当前内容同时存在空泛和无依据断言，例如没有关系事实输入，却拼出“双方没有在一起建造什么”。新标准要求**对牌义解释和建议有判断，对未提供的现实事实不装作知道**。

## 2. 本轮目标与能力边界

| 项目 | 要求 |
|---|---|
| 核心体验 | 看完首段，用户能说出“这次建议我优先看什么”；看完行动，知道做完是什么样 |
| 具体到哪里 | 明确匹配主题、意图、三张牌、位置和正逆位；不是对所有问题都可复用的鸡汤 |
| 自由文本 | 本轮不承诺本地规则理解任意问题正文。问题可作为用户记录展示，不能编造“我分析了你这段话”的体验 |
| 用户自解 | 单独保留其原话，不把复述当成理解，也不声称算法已经据此调整结论 |
| 原有约束 | 继续全程本地、固定抽牌、危机分流、保存原结果；允许拒绝 / 修改行动 |
| 暂不做 | 网络模型、本地模型部署、多轮问答、统计页、复杂知识图谱、随机同义句轮换 |

来源说明可以是“本地牌面解读 · 根据所选主题和三张牌整理”。在模式选择处一次说明“不会逐句分析问题正文”；正文不反复解释实现限制。不要因此隐藏自由输入，也不要把 AI 当成修复本地体验的唯一出口。

## 3. 表达标准：直接、有依据、可使用

### 允许明确说什么

- 牌义解释：“星币三逆位放在阻碍位，这次优先看协作是否具体。”
- 建议优先级：“先补一条能改变决定的信息，再继续比较选项。”
- 带核对条件的不同路径：“约定还不清楚，先明确一件共同任务；约定已经清楚但执行反复落空，再评估继续投入的成本。”
- 对已明确给出的事实，可以准确复述；本地规则未理解自由文本时，不自行提取或扩大其含义。

### 停止写什么

| 当前常见写法 | 问题 | 替换方向 |
|---|---|---|
| “这三张牌不是答案，是三个观察角度”占据整体解读 | 只有边界，没有观点 | 首句写这次最值得检查的具体事项 |
| 每段“如果把这张牌看成……” | 固定套壳，没有解释三牌关系 | 直接说明这一位置的贡献，再给需要核对的条件 |
| “不用今天决定”“不用马上处理”“不必告诉任何人”反复出现 | 每次都向后退，不区分任务 | 行动写清对象与完成标准；拒绝权留给现有操作 |
| “今天不用处理这件事” | 未知是否有期限，也替用户做了决定 | 陪伴模式缩小行动规模，不擅自宣布事情可以搁置 |
| “你的价值不取决于别人有没有看见” | 换到很多问题都成立，缺少这次的信息 | 说明具体要核对哪项投入、反馈或判断依据 |
| “哪一张最让你停下来，为什么”作为通用收尾 | 把解读任务又交回用户 | 追问本次判断里一个尚未确定的条件 |

不规定“也许 / 可能”出现零次；必要的条件保留。重复免责、机械软化与无信息安慰才是问题。也不靠增加文字量表现深度。

## 4. 结果结构

保留现有整体、逐牌、两种读法、行动、问句结构；本轮不为文案增加存储字段。

| 部分 | 应交付的价值 | 不通过的表现 |
|---|---|---|
| 整体 | 一句观察重点，随后说明三张牌如何形成支持、阻碍或转折；建议 2–3 句 | 只列关键词、只说不能预测、与任意三牌通用 |
| 逐牌 | 牌义与当前位置有关，说明这张牌对整体判断的贡献 | 同一张牌放任何位置都复制同一段百科 |
| 两种读法 | 两个可以核对的路径，各有适用条件和不同的下一步 | 固定“外部 / 内心”换词；两段都叫人慢慢想 |
| 行动 | 由具体牌义方向、主题和意图共同决定；有对象、步骤或完成标准 | 只因选择 decide 就永远列得失，companion 永远喝水 |
| 问句 | 追问当前重点的一项条件、证据或取舍 | 固定“哪个更松”“怎么温柔对待自己” |

三种意图改变任务：clarify 帮人找重点、区分待核对的部分；decide 给比较标准、信息优先级与可逆试验；companion 降低任务负担，但仍围绕牌面，不能只剩柔软的措辞。

保留塔罗的象征和画面感。可以把“兼顾、暂停、过渡受阻”写成三张牌之间的张力，再落到明确建议；不要把所有解读都改成机械的清单或管理术语。画面来自牌，现实细节来自用户明确提供的信息，两者各有来源。

## 5. 同牌示范 A：关系与合作

这是**人工编辑的目标示范，不是新算法输出，也不是对用户本人的解读**。合成主题为关系、意图为 clarify，三张牌依次是权杖王后逆位、星币三逆位、星币侍从正位。本地规则不读取具体关系事实。

当前代码生成的片段：

> 此刻的处境——权杖王后（逆位）（嫉妒、自我怀疑）；卡住你的东西——星币三（逆位）（配合不畅、敷衍了事）；可以试的下一步——星币侍从（学习、踏实）。这三张牌不是答案，是三个观察角度。
>
> 行动：今天为自己留一段不被打扰的时间，把这段关系里让你为难的事按轻重排个先后，不用马上处理。
>
> 反问：你现在最想学的是什么？

建议的内容方向：

**整体**

这组牌的重点是：让投入变成能执行的合作。权杖王后逆位提醒你检查投入与自信的关系，星币三逆位把阻碍放在配合方式，星币侍从则把下一步收拢到一件小事。我建议先明确一项共同任务，用实际配合来核对这段关系里的期待。

**逐牌**

- 权杖王后逆位 · 此刻：把注意力放在“投入是为了完成什么”。投入、表现和被认可可以分开看，先明确这次真正想推动的一件事。
- 星币三逆位 · 阻碍：协作需要能说清楚的约定。检查任务、责任和反馈是否明确，比继续猜测谁更在乎更能推进问题。
- 星币侍从正位 · 下一步：把期待缩成一次具体尝试。小到可以准备、执行和回看，才有机会得到有用的反馈。

**两种读法**

1. **先把约定说清。**共同目标或责任还模糊时，优先整理一件双方需要配合的事，写清各自要做什么。
2. **先检查执行。**已有清楚约定、却反复没有落实时，先看这项合作是否值得继续追加投入，别用更多付出来代替核对。

**行动**

用 10 分钟写一份具体提议：一起完成什么、各自负责什么、哪天确认进展。

**问句**

哪一项共同约定，最能检验你们能否配合？

这里的两种读法是条件分支，不能暗示任何一项已发生。行动的完成标准是写出提议，不要求对方参与、回复或同意；也不需要追加一段“不必发送”的套话。

## 6. 同牌示范 B：决定与过渡

合成主题为事业、意图为 decide；牌为星币二正位、宝剑四正位、宝剑六逆位。用“转行这件事我在怕什么”作为阅读背景；下列示范展示事业主题中的过渡问题，**不是现有本地算法从问题中识别出了转行**。实际规则若只能获得事业主题，应使用“方向调整”等一般表述，不能自动写“转行”。

> **整体：**这组牌的重点是过渡成本。星币二讲兼顾，宝剑四讲暂停，宝剑六逆位讲过渡受阻：先分清“调整方向要付出什么”和“眼下有没有余力承担”，再安排下一步的精力。
>
> **路径一：**可用时间或精力最紧时，先缩小试验规模，避免同时增加几项准备任务。
>
> **路径二：**最担心的代价还没有查证时，优先补一条信息，把已核实的成本与猜测分开。
>
> **行动：**用 20 分钟查看一个你正在考虑的岗位或项目的实际要求，记下已满足的一项、缺少的一项和一个待核实问题。
>
> **问句：**哪条关于过渡成本的信息，最会改变你接下来一周的安排？

有主张的是“先检查过渡成本”，不是替人决定辞职或假装知道其内心。若没有正在考虑的岗位 / 项目，结果应允许改写行动，不把不存在的选项当成事实。

## 7. 验收标准

先冻结 16 个代表样本：四主题 × 三意图各一例，共 12 例；另加 4 例“此刻 / 无具体问题”，覆盖正逆位及意义相近、相反的牌。再用 8 个定向对照覆盖换首牌、换阻碍牌、换末牌、换位置、翻正逆位、换主题、换意图、改变自由文本 / 自解。不是随机抽几个看起来好的例子。

| ID | 验收 |
|---|---|
| LQ01 | 每个首段都有可复述的观察重点，不能只是牌名目录或边界说明 |
| LQ02 | 三张牌都对整体解释有贡献；在语义方向明显不同的对照中换牌 / 换位置，判断依据随之变化 |
| LQ03 | 事业、关系、自我、去留不误借别的主题字段；问句与本次重点一致 |
| LQ04 | decide / companion 的行动不再被主题唯一决定；末牌方向明显改变时，行动或行动理由有实质变化 |
| LQ05 | 两种读法有不同的适用条件和建议方向，不靠同义词制造差异 |
| LQ06 | 普通完成结果的能力说明只集中出现一次；不强制含“不替你决定”等短语；必要条件句不因措辞统计而被删掉 |
| LQ07 | 不冒认用户情绪、第三方想法或关系事实；不默认紧急事项可以拖延；没有这些问题才能进入质量评分 |
| LQ08 | 相同受支持输入生成稳定结果；不靠随机换句隐藏内容单一；缺少映射有明确、可读的回退 |
| LQ09 | 自由文本仍未参与推理时，说明与实际一致；不会仅通过原文回显就被算作“回应了具体问题” |
| LQ10 | 本地全流程 0 模型请求，旧记录快照不重算，用户仍可拒绝 / 修改行动；既有安全分流和保存恢复不回退 |

人工内容评分每项 0–2 分：观点明确、三牌关联、主题匹配、行动具体、语言直接。0 为缺失 / 明显问题，1 为部分达到，2 为清楚有用。建议每例至少 8/10 且无单项 0；这是本轮提议的产品门槛，不是外部行业标准。

同样本盲看旧版和候选版，记录选择与理由；建议至少 12/16 更偏好候选版，平局不算获胜。由产品负责人 / 用户评审时须注明人数，AI 预审不能写成人工通过，也不能用小样本宣传普遍有效。最终检查“用户能否复述一个有用判断”，而不是数“可能”少了几个。

## 8. v2.1 后的产品修订：从检查问题到给出解释

### 判断与取舍

v2.1 比 v1 有进步，但还没解决用户最初的不满。它把“我不替你决定”换成了“这组牌值得先核对的是”，仍经常把解释任务交还给用户。**核对是编辑检验内容的办法，不该成为每段解读的固定口吻。** 用户要读到一个说得通的主张，以及三张牌如何支持、限制或改变这个主张。

“让语言更大胆”的具体要求是：明确建议先看什么、先做什么，并解释理由。允许写“这组牌把重点放在过渡成本”“先做一次小试验”；不需要先写一句免责声明，也不需要把每个判断改成问号。

下一轮优先级：

| 优先级 | 产品改变 | 具体要求 |
|---|---|---|
| P1 | 一个解释重点统领全文 | 首段不再等于阻碍牌的问句；三张牌要构成推进、制约或转折。样本 3 应说清为什么“大动作要审慎，小动作可以开始”，不能一边叫停、一边催促 |
| P1 | 行动和追问接住这个重点 | 删除尾巴不能算修复。行动的对象、规模或时机必须由整体解释决定；问句继续追问同一件事。样本 11 讲选项依赖谁，就不再转去问“最小的一次练习” |
| P1 | companion 减少负担，保留内容 | 可以给轻量体验或一个注意方向，不强制每次写字、打卡、记录感受。样本 13 应连接“热情—兼顾—细小的喜欢”，不能听完歌再做一遍余量自查 |
| P2 | 让普通抽牌也能得到改善 | 通过 12 张原型的表达验收后，再扩全牌；完整改造的完成口径是 78 张正逆位覆盖，而非 16 个精选例子漂亮 |

本轮不加新牌阵、追问流程或语气开关；不靠更多免责声明解决内容问题。继续使用现有字段与本地运行方式。

### 两段可直接讨论的目标样稿

以下是人工编辑提案，供确定产品声音；不是当前程序输出。两例都只使用样本已有的牌、主题与意图，不从问题正文推断生活经历。

**样本 3：权杖八逆位 / 宝剑骑士逆位 / 星币侍从逆位，事业 · clarify**

v2.1 的“后果有没有想过”接着“只想不做是可以先动的一步”，把要避免的状态写成了建议。目标不是简单把两个词换软，而是解释它们的关系：

> **整体：**这组牌的重点是把“做决定”和“做试验”分开。权杖八逆位提出节奏问题，宝剑骑士逆位提醒大动作先看后果，星币侍从逆位则把下一步拉回一次实际尝试。先做一个能停下来的小试验，用结果决定要不要加速。
>
> **读法一：**准备做的事会形成难以撤回的承诺时，先把关键后果写清，再确定试验边界。
>
> **读法二：**只是缺少一次实际体验时，把范围缩到二十分钟能完成的一步，先试再调整。
>
> **行动：**选一件与这次事业主题有关、二十分钟内可完成的小尝试，写清“做什么”和“到哪里停”，然后试一次。
>
> **问句：**这次小试验得到什么信息，才值得继续投入？

这段的立场是“先小试，再加速”。两种读法围绕承诺大小分支，不再分别讲“别冲动”和“去学习”。

事业场景的可选具体例：打开一份感兴趣的岗位描述，选一条技能要求，用二十分钟从自己的作品或经历里找出一个对应例子；找不到的记成一条待验证问题，到时间停下。产物就是“一条要求 + 一份证据或一个缺口”，据此决定下一步练什么。这是求职场景的编辑示例，不代表规则已从问题正文识别出求职。

**样本 13：权杖王后 / 星币二 / 圣杯侍从，此刻 · companion**

v2.1 的“留 10 分钟给一个小小的喜欢”本身可以成立，问题在于整体没有解释这件事为什么值得做，末尾还加了一道自查题。目标方向：

> **整体：**这组牌把热情收拢到一件小小的喜欢上。权杖王后带来向外的热度，星币二把它放进“同时兼顾”的张力里，圣杯侍从给出的落点很轻：挑一件此刻愿意靠近的事，让注意力在这里停一会儿。
>
> **行动：**挑一件此刻有兴趣的小事，给它五分钟：听一首歌、画两笔，或看看窗外的光。选一件就够。
>
> **问句：**哪一件小事，值得你把这五分钟留给它？

陪伴的完成标准是一次短暂的停留。这里不追加记录表、学习成果或余量核对；全版仍保留两种有实际差别的读法，不能把这段节选当完整输出契约。

| 2 · 事业 / decide | 待填 | 待填 | 待填 |
| 3 · 事业 / clarify | 待填 | 待填 | 待填 |
