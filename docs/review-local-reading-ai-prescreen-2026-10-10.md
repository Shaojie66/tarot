# 本地解读 v2 样稿 · AI 盲评预审

> 日期：2026-10-10；对象：`docs/local-reading-samples-2026-10-10.md` 的 16 个冻结样本（旧版 vs v2 样稿，顺序已打乱），提交 `afe8490`。

> **这是 AI 预审，不是人工评分，也不是 PRD 的“人工 ≥12/16”门槛。** 评审者是同一类模型，可能有共同偏好；风险审查员对同一版本和另两位的偏好有分歧。结论用来决定先修什么，不用来宣称达标。

## 2. 新版的问题（三人共同点，按影响排序）

1. **把阻碍位写成事实。** 所有阻碍说明都以“卡住的是……”开头，被读成对用户处境的断言：“答应的事比能做的多，已经开始漏球”“卡住的是拖延本身带来的消耗”“卡住的是谁负责什么”。在用户没提供任何信息的前提下，这是 PRD LQ07 要禁止的。
2. **具体的预设短语。** “带着疲惫硬做判断”（宝剑四）、“刚才那件小事里……”（圣杯侍从逆位的问句，用户没说过）、“再拖一个月”（死神逆位）、“你一直在回避……”类、“继续维持原样，你每个月实际付出的是什么”“你想立刻做的冲动”“离开某个状态”。
3. **主题错配。** 星币三 / 星币侍从 / 宝剑六这类牌的内容带明显的“协作 / 学习 / 离开”语境，关系问题（样本 1、5）读成职场协作，行动“查三条资料”与关系无关；去留问题被写成“分工和标准”（样本 11）。
4. **行动只来自末牌。** 与整体重点脱节（样本 1：重点是“协作缺少约定”，行动却是“做第一份功课”）。
5. **固定收尾句脱节。** “先把已经确认的和还需要核对的分开”“放进选择里看：先补信息”与后面的行动不呼应。
6. **整体第二句“从「X」出发，卡在「Y」，下一步指向「Z」”机械。**

没有评审认为新版“防御性过强、什么都不敢说”；旧版的主要问题被一致指出：首段只是牌名清单，逆位免责句逐牌重复，行动 / 问句是通用模板（“为自己做一件很小的照顾”“此刻你最想被什么温柔地对待”），且有“情感表达还不够成熟”“鲁莽”“不成熟”这类评判，以及“你知道自己想要什么”“你太累了”等断言。

## 3. 建议的下一步（v2.1，仍是样稿阶段）

1. **改写阻碍位句式**：不再用“卡住的是……”，改成“这个位置提示一个可核对的方向：……”，把断言改成待检验的条件；`obstacle.focus` 同理，以“可能 / 需要先看”的语气描述。
2. **清掉具体预设**：删或改“带着疲惫硬做判断”“刚才那件小事”“再拖一个月”“已经开始漏球”“你想立刻做的冲动”等。
3. **主题适配**：关系 / 去留主题不套协作和过渡成本的语境；行动里的对象随主题换；必要时按主题为个别牌写变体，而不是扩写全部牌。
4. **行动来源**：让行动能由“阻碍牌的方向 + 末牌”共同决定（例如阻碍牌给对象，末牌给动作规模），而不是只看末牌。
5. **重写收尾句与整体第二句**，让它们引用本组牌的内容，而不是固定句。
6. 重新生成盲看样本，再做一轮评审；**人工评分仍需要你或编辑做**，AI 预审不能替代。
7. 在 1–6 的内容通过人工评分之前，不扩写到全部 78 张牌。

# 第二轮：v2.1 样稿（`local-v2.1-sample`）

> 修订依据上面的第 2–3 节。另起 3 个**新的**子智能体（目标用户 / 文案编辑 / 风险审查）对 `docs/local-reading-samples-local-v2.1-sample.md` 盲评，评审者不知道上一轮，也没读对照表。仍是 AI 预审。

## 改了什么

- 阻碍位不再写成事实：去掉“卡住的是……”，改成可核对的点（“有没有……”“对不对得上”）和一般性的条件句；首句改成“这组牌值得先核对的是：……”。
- 清掉预设短语（“刚才那件小事”“带着疲惫硬做判断”“再拖一个月”“已经开始漏球”等），测试里加了全文扫描。
- 个别牌按主题写变体（星币三 / 星币侍从 / 宝剑六 / 星币二的关系变体，星币三的去留变体），关系行动只涉及自己。
- 行动 = 末牌的动作 + “做的时候留意：{阻碍牌的核对点}”，让行动与整体判断连起来（第二轮发现对陪伴意图不合适，见下）。
- 整体第二句、收尾句改为引用本组牌内容；骑士逆位的“先等一晚”补了“有期限的事以期限为准”。

## 第二轮仍指出的问题（v2.2 待办）

1. **陪伴意图的行动与整体脱节**（样本 12、13、15）：整体讲“要兼顾的事有没有超出余量”，行动却是“留 10 分钟给小小的喜欢”，末尾还附“做的时候留意：兼顾有没有超出余量”。建议 companion 不附带核对点，行动本身就应围绕牌面。
2. **机械重复的句式**：“做的时候留意：……”“先从最容易核对的那一点开始”“这次把步子放小”“……的提示：”开头、“X 是眼下的底色，Y 是可以先动的一步”（抽象压缩过度）。
3. **仍有预设**：“想走却没走”“想学的东西已经明确”“已经学了不少”“你想了很久的计划”“把‘走’之前必须先处理的一件事”（默认用户要走）“过渡期需要的资源够不够”（无具体问题时预设在过渡）“当初答应是出于‘应该’”。
4. **问句错配**：星币侍从的“要开始这件事，最小的一次练习是什么？”在 decide 与“此刻”样本里不贴题。
5. **重点之间互相打架**：样本 3 首段的“后果有没有想过”与“只想不做”（宝剑骑士逆位 + 星币侍从逆位）不是一件事，需要在整体里处理“两个重点”或让末牌不抢话。
6. **牌义条目偏薄**，三牌关联需要补强（让位置说明引用该牌的画面或象征，而不是只写一句提示）。

# 第三轮：v2.2 样稿（`local-v2.2-sample`）对冻结的 v2.1

## 候选的退步与问题（两位评审共同的）

1. **“负担与过渡”被套到并没提过渡的情境**（样本 4 事业·陪伴、8 自我·decide、10 去留·clarify）：整体说“不用做任何决定”，读法却讲“评估要不要开始过渡”（样本 4，前后矛盾）；“过渡”是用户没提过的前提；宝剑骑士只剩“果断直接这一层背景”，没有进入主张（样本 8）。
2. **关系主题被写成职场协作**（样本 1）：“投入与配合”的读法和牌面说明仍是“任务、责任和反馈”“追加投入”，只有行动单独改成了关系版本；问句“哪一项约定”预设用户有约定。
3. **“安顿与恢复”的行动和问句在样本 6、9、14 里几乎一样**（慢呼吸 + 温水），样本 14 里死神（逆位）在读法和行动里完全没用上。
4. **同一个主张下，读法和行动偶尔脱节**：样本 10 的读法讲“拖着脚步”，行动却偏向推进（评审认为是旧版的“是什么在拖着脚步”更贴）。
5. **未命中主张的样本**（5、7、16）保留了 v2.1 的问题：硬接的“做的时候留意”（5、7）、“先从最容易核对的那一点开始”这类空话；样本 16 的整体仍问“过渡期资源够不够”，而行动讲冲动。
6. 评审也指出候选的亮点：样本 3、6、9、11、12、13 的主张与行动、问句一气呵成（“把做决定和做试验分开”“先稳一稳”“先试，再用结果比较选项”“把热情收拢到一件小小的喜欢上”）。

## 下一步（v2.3，仍是样稿）

1. 主张的适用范围要收紧：`load-transition` 不能因为牌里有“休息、过重、结束”就套给没提过渡的陪伴 / 自我情境；需要加入主题或意图条件，或把读法里的“开始过渡”改成不预设的说法。
2. 主张内容按主题写变体（关系、去留、自我、事业），而不只是行动：读法和牌面说明里的“任务 / 责任 / 追加投入”在关系主题要换。
3. `settle-feelings` 的行动、问句要随牌面区分（高塔余波、死神阻力、宝剑四焦躁各自不同），并让没进入角色的牌（样本 14 的死神）进入读法或转折。
4. 未命中主张的 3 个样本要补主张或改成不带硬接尾巴的路径。
5. 人工评分仍需要你做，建议先看 3、4、8、10、14（好与坏的代表）。

## 风险审查员补充的、前两位没单独强调的问题

6. **主张里的关系句把牌义写成了用户的状态**（这是候选相对 v2.1 的新问题）：整体第二句用“X 说明 / 指出 / 带来 …”描述每张牌，读起来是在断言：
   - “圣杯侍从（逆位）说明情绪起伏比较大”“宝剑四（逆位）带来停不下来的感觉”（样本 6、9、14，直接冒认用户情绪）；
   - “星币三（逆位）指出配合方式有缺口”“星币二（逆位）指出承诺已经偏多”“死神给出一个正在收尾的阶段”（样本 1、4、8，凭牌确认处境）；
   - “比继续自责更有用”（样本 1，冒认用户在自责）；“先停一停、缓一缓，比继续硬撑更有用”（预设在硬撑）。
   
   v2.1 用“……的提示：”开头的牌说明，口气反而更克制。**修法**：把 `roles.relation` 和 `detail` 写成条件或提示口径（“这张牌可能在提示……”“如果……，……”），并在测试里加一条针对这类“说明 / 指出 / 带来 + 用户状态”的扫描。
7. **主张预设“过渡 / 离开 / 收尾”**（样本 2、8、10、16）：“先处理一个跟着你的问题，再谈换环境”“读法一仍写着再评估要不要开始过渡”。
8. **期限保护丢了**：样本 3 的候选没有保留“有期限的事以期限为准”；样本 4、10 的“其余明天再说 / 可以延期的先延期，今天就处理掉”没有紧急例外。陪伴 / 减负类的行动应统一带上“有期限的事以期限为准”。
9. **仍有预设“有一件待办 / 有一个想了很久的计划”**（样本 3、15）。
10. **亮点**：样本 4 的“把一项不紧急的安排挪到明天”、样本 10 的“本周内……截止日期”、样本 3、11、15 的行动更具体、更可做。

## 总体判断

主张机制让整体、读法、行动、问句更像讲同一件事（观点、三牌关联、语言三位评审都多数偏好候选），但在**风险**一侧退步：关系句的“说明 / 指出”口径放大了断言。**v2.2 不应当被当作比 v2.1 全面更好**。下一步 v2.3 先修 6、7、8，再做主题变体和读法覆盖，再重新比较；人工评分仍然要做，且建议优先看样本 1、4、6、8、10、14。

# 第四步（v2.3 前三条，已实现，**未重新评审**）

针对第三轮风险审查提出的 6、7、8：

- **关系句口径**：每个主张里每张牌的 `relation` 都以“可能……”开头，`detail` 改为条件句（“如果……”）；测试扫描禁止“说明你 / 说明情绪 / 指出承诺 / 比继续自责更有用 / 比继续硬撑更有用（非条件句）/ 已经偏多”等；命中主张的样本整体里至少两处“可能”。
- **适用范围**：“负担与过渡”新增 `requireAny`（过渡 / 过渡受阻 / 收尾），至少一张牌真的在讲这些才命中，所以样本 career-companion（权杖王后逆位 / 宝剑四 / 星币二逆位）不再套“过渡”；读法改成“如果正在考虑一个变动，……”，不预设用户要开始变动。
- **期限保护**：主张里和逐牌内容里凡是建议延期 / 顺延 / 暂放 / 留到明天 / 明天再说 / 明天同一时间再读，一律带“不紧急”或“有期限的事以期限为准”，测试全文扫描；小试验主张的读法一补上期限句。

没有重新跑盲评；上面样本 1（关系里的任务 / 责任 / 追加投入）、14（死神未进读法）、6 / 9 / 14 的行动雷同、预设“有一件待办”等问题**仍未处理**。重新评审前，v2.3 不能当作比 v2.1 更好的证据。
