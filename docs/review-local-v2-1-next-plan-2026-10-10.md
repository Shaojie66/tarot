# 本地解读 v2.1 技术复评与下一轮计划

> 日期：2026-10-10；代码基线：`00364cb`；内容版本：`local-v2.1-sample`。
> 本次交付仅为文档。产品表达、目标样稿与人工校准表见 [PRD 第 8 节](prd-local-reading-quality-2026-10-10.md#8-v21-后的产品修订从检查问题到给出解释)，执行顺序见 [PLAN v1.5](PLAN.md)。下列实现建议属于待办。

## 1. 结论

**继续推进 v2.2，但目标应是完成三牌之间的解释链。** 当前最主要的缺陷在内容组合方式：阻碍牌独占重点，首牌只提供背景标签，末牌独立决定动作与追问。删除机械句式可以改善表面，无法让这几部分自动讲同一件事。

v2.1 已交付 12 张牌正逆位的内容原型、局部主题变体、确定性路由和内容版本标记。两轮 AI 预审也已有记录。这些应算已完成，原计划的“尚未实施”已纠正。完整本地质量改造仍需要组合规则、人工内容验收和全牌覆盖。

## 2. 普通抽牌的覆盖率只有 0.289%

[`local.ts:81`](../src/features/reading/local.ts#L81) 要求三张牌全部有 v2 条目才使用新结构；[`local.ts:144`](../src/features/reading/local.ts#L144) 在任一张缺失时整体回到 v1。当前数据有 12 个 cardId、各含正逆位，共 24 个朝向。

抽牌使用拒绝采样和 Fisher–Yates 洗牌，再取前三张，见 [`random.ts:5`](../src/features/draw/random.ts#L5) 和 [`draw.ts:21`](../src/features/draw/draw.ts#L21)。在随机源均匀的假设下：

```text
P(三张均在样稿库) = C(12, 3) / C(78, 3)
                 = 220 / 76076
                 = 0.2891845%
```

这是规则推导的概率，不是用户流量实测。正逆位开关不改变它，因为这 12 张的两面都有内容。其余约 99.71% 的普通三牌组合仍走 v1。**12/78 的单牌覆盖率不能当作结果覆盖率。**

产品后果：精选样本的改善很难在日常抽牌中遇到。当前路由可以作为样稿阶段的整体回退；样稿通过后必须安排全牌扩写。禁止偏置抽牌去制造更多新模板命中。完整交付时用 78 张、156 个朝向的完备性证明路由覆盖 100%，不必穷举所有三牌正文。

固定短语扫描仍可作为已知问题的回归检查，但不能证明语言自然、行动相关或没有虚构前提。当前测试用“含 `时，`”“行动超过 20 字”“问号结尾”代理条件、完成标准和开放问题，见 [`local-quality.test.ts:37`](../evals/local-quality.test.ts#L37)。这些断言验证的是字面形式，测试名称与报告不能把它们写成语义验收。

原始例子可在 [v2.1 样本](local-reading-samples-local-v2.1-sample.md) 的 2、3、11、13、15 找到。样本 2 的追问“同样的问题，最近三次是在什么情境下出现的？”也仍默认问题反复发生；这种前提问题要随内容修正，不能仅靠继续扩充禁词表。

## 5. 建议的最小实现顺序

### 先选解释，再渲染句子

在现有 12 张内引入少量编辑可维护的组合规则。规则输入是三张牌各自的角色、主题与意图；规则输出是共同重点、三牌之间的关系，以及匹配的行动 / 问句。优先做样本已暴露的“节奏与试验”“负担与过渡”“投入与配合”“热情与兼顾”，不要一次建大型牌义知识图谱。

```text
三张牌的编辑条目 + 位置 + 主题 + 意图
  → 选择共同重点，说明支持 / 制约 / 转折
  → 按同一重点组织两条条件分支
  → 选行动对象、规模和时机 → 选对应追问
  → 渲染现有 ReadingResult 字段
```

需要组合属性时，先在内容数据中增加小型、显式的编辑标记，不从中文句子临时猜关键词。可以在合成评测里记录 `focusId`、规则 ID 和三张牌的贡献，方便追查；这些是内部生成数据，不要求新增记录字段或数据库迁移。最终仍由人工检查解释是否成立，三张牌的 ID 都被记录不等于关联有质量。

companion 使用同一解释重点，换成低负担动作；取消强制附加核对、写字或总结。decide 选择比较条件、信息优先级或可逆尝试；clarify 帮助分清一个关键区别。保留本地不解析自由文本、全程不调模型的能力范围。

### 让测试检查行为，内容审稿检查价值

| 检查 | 最小退出条件 |
|---|---|
| 三牌贡献 | 在预先指定的相反语义对照中，换首牌改变共同解释或行动理由；换阻碍改变动作对象、约束或时机。仅替换牌名 / 尾句不计；语义相近的牌不强制制造差异 |
| 一致性 | 样本 3 明确区分审慎承诺与轻量试验；两条读法与行动不相互命令；样本 2 不预设用户决定离开 |
| 意图与问句 | 样本 11 的问句继续讨论选项；样本 13 无额外容量考核；样本 15 的陪伴不预设学习项目 |
| 主题与位置 | 将有主题变体的牌轮流放在三个位置，检查整体、逐牌、行动、问句；事业与关系不得只换一个称谓 |
| 冻结对比 | 明确输出 v2.1 vs v2.2；16 例同输入；8 类原有定向对照继续保留；另加 8 例预先保留的新组合，区别于换输入的定向测试 |
| 人工评分 | 按 PRD 逐例评分；同一评审在同轮比较基线与候选，记录退步项。四例校准不能算正式 16 例通过；AI 预审不能填入人工栏 |
| 覆盖与回归 | 样稿阶段计算真实路由覆盖；全牌阶段校验 156 个朝向、三个位置的结构，并人工审稿与抽查跨批组合；固定牌、0 模型请求、内容版本、历史快照及保存恢复保持原契约 |

自动检查沿用 `pnpm check`。未来改到页面再补 build / E2E；这一轮内容结构设计不依赖真实模型，也不需要为文案更新记录 schema。
