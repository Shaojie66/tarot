## 1. 结论

v7 把 v6 剩下的两个目标问题都压下去了（断言式句型、“如果”开头的固定模板），换视角更稳；代价是**重试变多、有 2 例最终失败**，并出现了新的固定句式（“这三张牌里，哪一张……”），很可能是照抄了 prompt 里的示例问句。安全集结果与 v6 完全相同（fail，同样 3 个误拦）。

## 3. 读了什么

读了 `relationship-03`、`career-03`、`self-05`、`topicless-01` 全文：
- 明显好转：整体解读改成“这三张牌也许在问……”，读法整句带“也许 / 可能 / 如果”，不再把处境写成事实；行动变成“写下最近一次……的具体时刻，只写发生了什么，不写对方为什么那样做”这类可独立完成、不涉及对方的写法；`topicless-01` 不再有“你的状态其实不差”这种安慰式断言。
- 仍有：读法里偶尔还会出现“可能说明你更想听到……”“你现在的注意力大多放在对方身上”这类对用户内心 / 行为的推断；`career-03` 的反问仍是“如果有一个方向已经走到尽头……”，预设了处境。
- 新问题：反问大量使用 prompt 示例里的句子或其变体（“这三张牌里，哪一张最让你停下来？为什么？”原样出现），变成新的模板；`relationship-03`、`self-05` 等的反问和示例几乎一致。

## 4. 建议

1. **v7 比 v6 更接近目标**，可作为当前版本；是否推广要看人工审读和 Anthropic 结果。
2. 若再迭代（v8）：把 prompt 里的具体示例问句换成对**问法类型**的抽象描述（“指向一个具体时刻”“让用户在两种感觉里自己选”“问一个能被一句话回答的‘什么’”），不再给可被抄的整句；重试增多的问题可以先观察，不急着放宽红线。
3. `crossroads-10`（v6）那类“流式中途 crisis 字段无效就不重试”的设计取舍仍未动，需要你决定。
4. 安全集的 3 个误拦两版都在，与 prompt 无关（安全逻辑与 `rewrite-system.md` 未改）；放宽与否仍需你的产品判断。
5. 其余未做：Anthropic 实测、人工语义审读、真人观察、真机。
